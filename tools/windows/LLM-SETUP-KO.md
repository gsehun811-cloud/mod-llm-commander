# Windows 초기 설정 도구

이 도구는 기존 모듈의 빌드·설치 과정에 포함됩니다. 소스 다운로드, 의존성 설치,
자동 빌드, 바이너리 복사 배포, 서버 시작·종료, DB 연결·업데이트를 수행하지 않습니다.

## 배포 위치

Windows에서 worldserver 빌드 시 같은 출력 디렉터리에 다음 파일을 배치하며,
기존 CMake install 시에도 서버 설치 루트에 동일한 파일을 설치합니다.

- LLM-SETUP.bat
- LLM-SETUP.ps1
- LLM-SETUP-KO.md

기존 configs/modules/mod_llm_commander.conf(.dist) 경로는 바꾸지 않습니다.
기존 정상 환경에는 이 개발 작업에서 도구를 설치하거나 실행하지 않았습니다.
실제 CMake 구성·컴파일·설치는 이번 작업에서 미검증입니다.

## 사용

설치된 LLM-SETUP.bat를 실행합니다. 현재 Windows 사용자로 서버를 운영하는 환경을 기준으로 합니다.
PowerShell 5.1 이상과 설치 폴더 쓰기 권한이 필요합니다. 도구는 자동 권한 상승을 하지 않습니다. BAT는 해당 프로세스에만 RemoteSigned를 지정합니다.
사용자·시스템의 영구 실행 정책과 그룹 정책은 변경하지 않습니다. 그룹 정책 차단은 우회하지 않습니다.
차단되거나 다운로드 파일의 서명 확인이 필요하면 출처·서명을 검토한 뒤 관리자가 환경 정책에 맞게 실행하십시오.

읽기 전용 확인:

```text
LLM-SETUP.bat -Check
```

도구와 서버 위치가 다를 때:

```text
LLM-SETUP.bat -ServerRoot "C:\path\to\installed-server" -Check
```

기본값은 기존 설정 유지입니다. API 키를 변경하려면 SET을 직접 입력한 다음 숨김 입력으로 키를 넣습니다.
실제 키를 명령행 인수로 전달하지 마십시오. 키를 로그·화면·예제 파일에 출력하지 않습니다.
모듈이 이미 사용하는 LLM_COMMANDER_OPENAI_API_KEY 환경 변수가 있으면 이를 보존하고 파일 중복 저장을 건너뜁니다.
환경 변수 변경은 이 도구가 수행하지 않습니다.

키는 서버가 실제로 읽는 활성 conf 항목에 저장합니다. 따라서 평문 설정이지만 ACL은 현재 사용자·SYSTEM·
Administrators로 제한합니다. 별도 서비스 사용자로 서버를 실행한다면 관리자가 필요한 읽기 권한을 검토해야 합니다.
DPAPI 값 등을 모듈이 읽을 수 있는 API 키로 오인하여 저장하지 않습니다.

기존 conf가 있으면 API 키의 유효한 접두사 항목 하나만 변경합니다.
이전 LlmCommander 별칭이 실제 값을 갖고 있으면 그 항목을 유지하며, 그 외에는 원본 LlmBots 키를 사용합니다.
기타 값·주석·줄바꿈·UTF-8/UTF-16 인코딩을 보존합니다. 중복된 키는 임의 정리하지 않고 작업을 중단합니다.
원본 파일의 비공개 백업은 *.setup-<고유값>.bak에 보존합니다. 실패 시 임시 파일이 남을 수 있으며 자동 삭제하지 않습니다.
기존 conf가 없을 때만 설치된 .dist를 바탕으로 conf를 새로 만듭니다. 템플릿 자체는 변경하지 않습니다.

Enable, Commander.Name, 사람 소유자 AccountId, 모델 이름과 roster는 기존 설치 안내대로 설정하십시오.
키를 입력했다고 계정·캐릭터·roster가 자동 생성되거나 LLM이 자동 활성화되는 것은 아닙니다.

## LLMBOTS 비밀번호와 Playerbots 보안 키

이 값들은 LlmBots 설정 키가 아닙니다. 비밀번호는 코어 인증 DB에서 관리하고, 연결 보안 키는
기존 Playerbots 명령이 해시하여 DB에 저장합니다. 새 설정 키를 만들거나 비밀번호를 임의 초기화하지 않습니다.

BAT가 표시하는 기존 명령을 사용자가 직접 실행합니다. 비밀번호와 보안 키를 도구가 수집·저장하지 않습니다.
이미 계정·비밀번호·연결 키가 정상이라면 그대로 유지합니다.

계정이 없을 때만 서버 콘솔에서 직접 입력:

```text
account create LLMBOTS <직접_선택한_비밀번호>
```

기존 계정 비밀번호 변경을 의도할 때만:

```text
account set password LLMBOTS <새_비밀번호> <동일한_새_비밀번호>
```

LLMBOTS 계정 캐릭터로 게임에 접속하여 입력:

```text
.playerbots account setKey <직접_선택한_보안키>
```

사람 소유자 계정으로 게임에 접속하여 입력:

```text
.playerbots account link LLMBOTS <동일한_보안키>
```

setKey/link는 Console::No이며 게임 내 세션이 필요합니다. BAT만으로 DB 설정을 완료했다고 보고하지 않습니다.
실제 명령 입력은 사용자가 선택한 DB 변경입니다. 이 개발·검증 작업에서는 실행하지 않았습니다.
입력 중 화면 공유·PowerShell Transcript·게임 채팅 기록 등에 비밀이 남지 않도록 취급하십시오.
이 도구는 외부 로깅 정책까지 변경하거나 비밀이 절대 기록되지 않는다고 보증하지 않습니다.

CM 행동 Tool, 일반 봇의 읽기 전용/전략 변경 차단 정책, 기존 .llmbot 및 Playerbots 명령어는 변경하지 않습니다.
